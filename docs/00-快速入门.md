# 快速入门

> 本篇面向零基础新手，用最直白的语言带你跑通整个流程。如果你已经熟悉命令行和 Node.js，可以直接跳到 [项目总览](./01-项目总览.md)。

---

## 一、这个脚手架是做什么的？

想象你去宜家买家具，拿到的不是成品沙发，而是一箱零件 + 一份说明书。你照着说明书组装，就能得到一个完整的沙发。

**mirajay-cli 就是前端领域的"宜家套装"**：

- 你运行一条命令，它会问你几个问题（要 Vue 还是 React？要什么 UI 库？要不要 ESLint？）
- 根据你的回答，它自动生成一个**可以直接运行的前端项目**
- 生成的项目已经配好了构建工具、代码规范、测试框架、Git 提交规范等

**一句话总结：输入几行命令 → 得到一个开箱即用的前端项目。**

---

## 二、你需要先准备什么？

### 1. 安装 Node.js

Node.js 是运行 JavaScript 的环境（浏览器之外也能跑 JS）。

- 去 [nodejs.org](https://nodejs.org/) 下载 LTS 版本（>= 24.18.0）
- 安装后在终端输入 `node --version`，看到类似 `v24.18.0` 就说明装好了

> **什么是终端？**
> - Windows：按 `Win + R`，输入 `cmd` 或 `powershell`
> - macOS：打开"终端"应用（Terminal）

### 2. 安装 pnpm

pnpm 是一个包管理器（类似 npm，但更快）。打开终端执行：

```bash
npm install -g pnpm
```

验证：`pnpm --version`，看到版本号即可。

### 3. 安装 Git

Git 是代码版本管理工具。去 [git-scm.com](https://git-scm.com/) 下载安装。

验证：`git --version`。

## 三、安装脚手架

### 方式一：从源码安装（开发/学习用途）

```bash
# 1. 进入项目目录
cd /path/to/mirajay-cli

# 2. 安装依赖
pnpm install

# 3. 构建脚手架
pnpm build

# 4. 全局链接（这样你在任何地方都能用 mirajay-cli 命令）
pnpm link --global
```

### 方式二：从 npm 安装（发布后）

```bash
pnpm add -g mirajay-cli
# 或
npm install -g mirajay-cli
```

验证安装成功：

```bash
mirajay-cli --help
```

看到帮助信息就说明装好了。

## 四、创建你的第一个项目

### 交互式创建（推荐新手）

```bash
mirajay-cli create my-app
```

然后脚手架会一步步问你问题，你只需要选择即可：

```
  mirajay-cli - 企业级前端脚手架
  桌面 Web · 移动端 · 微前端

? 项目名称 › my-app
? 选择项目类型 › 桌面 Web 应用
? 选择前端框架 › Vue
? 是否使用 TypeScript? › Yes
? 选择 UI 组件库 › Element Plus
? 选择 CSS 框架 › Tailwind CSS
? 是否使用 Monorepo (Turborepo) 管理? › Yes
? 选择工程化预设 › Standard（推荐）
? 选择包管理器 › pnpm（推荐）
? 是否初始化 Git 仓库? › Yes
```

回答完所有问题后，脚手架会自动：
1. 复制模板文件到 `my-app/` 目录
2. 根据你的选择，用 EJS 模板引擎渲染出最终代码
3. 合并工程化配置（ESLint、Prettier 等）
4. 安装 npm 依赖
5. 初始化 Git 仓库

### 一键创建（使用默认配置）

```bash
mirajay-cli create my-app -y
```

这会跳过所有问答，直接用默认配置创建：
- 桌面 Web + Vue + Element Plus + Tailwind CSS
- TypeScript + Monorepo + Standard 工程化预设
- pnpm + Git

## 五、启动项目

创建完成后，终端会提示你下一步操作。通常是这样：

```bash
# 进入项目目录
cd my-app

# 启动开发服务器
pnpm dev
```

终端会输出类似：

```
  VITE v6.x.x  ready in 320 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

**在浏览器打开 `http://localhost:5173/` 就能看到你的网页了！**

> ⚠️ 重要：`pnpm dev` 启动的是一个持续运行的本地服务器。**不要关闭终端**，关闭后浏览器页面将无法访问。
> 按 `Ctrl + C` 可以停止服务器。

## 六、常用命令速查

在生成的项目目录中，你可以使用以下命令：

| 命令 | 作用 |
|------|------|
| `pnpm dev` | 启动开发服务器（边写代码边看效果） |
| `pnpm build` | 打包项目（生成可部署的静态文件） |
| `pnpm preview` | 预览打包后的效果 |
| `pnpm lint` | 代码规范检查 |
| `pnpm test` | 运行单元测试 |
| `pnpm commit` | 规范化提交代码（交互式） |

## 七、生成的项目长什么样？

如果你选择了 Monorepo，目录结构大致如下：

```text
my-app/
├── apps/
│   └── web/              # 主应用代码在这里
│       ├── src/          # 你的源码
│       ├── index.html    # 网页入口
│       ├── package.json  # 应用依赖
│       └── vite.config.ts # Vite 构建配置
├── packages/
│   └── shared/           # 多应用共享的代码
├── turbo.json            # Turborepo 任务编排配置
├── pnpm-workspace.yaml   # pnpm 工作区配置
└── package.json          # 根目录脚本
```

如果你没有选 Monorepo，目录更简单：

```text
my-app/
├── src/             # 源码
├── index.html       # 网页入口
├── package.json     # 依赖配置
└── vite.config.ts   # 构建配置
```

## 八、遇到问题怎么办？

### 1. 运行 `mirajay-cli` 提示 command not found

说明全局链接没生效。尝试重新执行 `pnpm link --global`，或者直接用：

```bash
node /path/to/mirajay-cli/bin/cli.mjs create my-app
```

### 2. 启动报错 "Cannot find module"

可能依赖没装好。进入项目目录重新安装：

```bash
cd my-app
pnpm install
```

### 3. 想检查环境是否正常

```bash
mirajay-cli doctor
```

这个命令会检查 Node.js、pnpm、yarn、Git、Flutter 等工具是否安装正常。
